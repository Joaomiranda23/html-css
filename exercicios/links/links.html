usando links externos

Você pode colocar links externos com a tag <a href="url completa">

por exemplo vou colocar um link de um repositorio no github,

utilizamos dentro do link da url as tags <target> e <rel>, elas servem para escolhermos se queremos que o usuario, abra o link em uma nova aba, ou se será aberta na mesma aba. A tag <target="_blank"> serve para direcionarmos o link para uma nova aba.
