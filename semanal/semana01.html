Hierarquia de títulos

Uma das primeiras coisas que estudei esse semana foi a hierarquia de títulos.
As tag seguem de h1 até h6, sendo h1 o título mais importante do seu arquivo. Usamos h2 logo após o h1 para criar um subtítulo dentro de h1
Após isso, podemos usar h2 para criar um outro título, dentro desse h2, podemos criar uma h3 para criar um subtítulo dentro dele, e assim por diante.

Listas

Listas Ol são usadas para criar uma lista onde o usuario deve seguir passo a passo como por exemplo, segue abaixo uma lista para fazer um bolo

  1. Pegar os ingredientes
  2. pegar os utensilios
  3. quebrar os ovos
  4. pesar os ingredientes

as ul são listas onde o usuario não precisa seguir uma ordem específica

Você pode criar listas uma dentro de outra também

tambem temos as listas de definição, onde dt é a tag para determinarmos o termo, e dd é a tag para colocarmos a definição desse termo. Temos também a tag abbr para criar uma abreviação por exemplo HTML
