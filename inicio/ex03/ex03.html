Texto marcado

Podemos usar a tag MARK, para marcar um texto

Para mudar a cor do seu marcador de textos, usamos a tag <style="background-color: cor;"> que vai dentro da tag mark

Usando a tag style, dentro da tag mark, você não consegue definir uma cor padrão para todos os marks do seu site, tendo que adicionar um style para cada mark.
Para podermos defifnir uma cor padrão, podemos criar uma tag style, dentro da tag HEAD, sendo conhecida como seletor.
ficaria basicamente assim:
<style>
mark {
background-color: limegreen
}
<style>

Texto grande e pequeno

Para criar um texto grande usamos a tag <big> e para um texto pequeno, usamos a tag <small>, porém, a tag BIG, já não é mais uma tag semântica dentro de html5, para aumentarmos o tamanho de um texto, devemos usar CSS.
Apenas a tag SMALL, ainda é considerada semântica

Texto deletado

Podemos marcar um texto como excluído, para indicar que ele deve ser lido, mas não considerado

Texto inserido

podemos marcar um texto como inserido, para dar uma ênfase e indicar que ele foi adicionado depois

Texto sobrescrito

Usamos a tag <sup> para deixarmos um texto sobrescrito do outro, ou seja, acima de outras palavras, como por exempo x20+3
Nesse caso, eu deixei o 20, sobrescrito do X

Texto subscrito

Usamos a tag <sub> para deixarmos um texto subscrito do outro, ou seja, abaixo de outras palavras, como por exemplo; H20
Nesse caso, eu deixei o 2, subscrito do H, deixei ele abaixo
